# 認識エンジンの足し方

新しい認識モデルを kikitori に足したい開発者向けの手順です。コアと、ほかのエンジンは変えずに、エンジンを 1 つ足すだけで加えられる作りにしてあります。

## 考え方

- コアはモデルの種類を知りません。エンジンのクレートは `kikitori-core` の型だけに依存し、互いに依存しません。
- 認識（`AsrEngine`）、発話区間（`Vad`）、話者分離（`Diarizer`）は別の口です。認識と話者分離は独立していて、パイプラインが両者の結果を突き合わせて話者を割り当てます。
- 重みは配布元（Hugging Face や sherpa-onnx の Release）の元のファイルをそのまま読みます。変換・量子化した重みを配ったり、手元のキャッシュに派生物を書いたりしません。
- 長さ順の束ねやバッチ化は、エンジンの内側の事情です。

## 認識エンジンの口

エンジンは `AsrEngine` を実装します。入力は 16 kHz モノラルの波形（`AsrRequest`）で、出力は本文と、あれば時刻つきのトークン（`AsrOutput`）です。

- `capabilities()`：トークンの時刻を出せるか、語彙ヒント（`context`）を受けるか、1 回に渡せる最長の秒数、対応する数値精度（dtype）を宣言します。
- `transcribe()`：区間の波形の列を受け、同じ順に結果を返します。KV キャッシュなどの状態を持てるよう、`&mut self` です。
- トークンの時刻を出せないエンジン（Qwen3-ASR や kana-whisper など）は、`tokens` を空で返します。パイプラインは `timestamps` が偽のエンジンを、区間の単位で話者に割り当てます。
- 語彙ヒントに対応しないエンジンは、`context` を無視してかまいません。

## 足す手順

1. **クレートを足す**。`crates/` の下に、エンジンのクレートを作ります。`kikitori-core` だけに依存させます。重い依存（candle や ONNX Runtime など）はこのクレートの中に閉じ込めます。
2. **`AsrEngine` を実装する**。重みは `Weights`（取得済みのファイルのパスの列）から読みます。計算機の指定（`LoadOptions` の `device` と `dtype`）に従い、`dtype` が `None` のときはエンジンの既定を使います。GPU の初期化に失敗したり panic したりするときは、失敗として返し、CPU に戻れるようにします。
3. **`specs()` を実装する**。クレートに `pub fn specs() -> &'static [EngineSpec]` を置きます。`EngineSpec` は次の 4 つを持ちます。
   - `name`：`--asr` などで選ぶ名前
   - `hf_repo`：Hugging Face のリポジトリ名。`--asr hf:<リポジトリ名>` でも選べる
   - `files`：取得する必要なファイル
   - `load`：重みからエンジンを作る関数
4. **CLI に束ねる**。`kikitori` クレートの Cargo の feature に 1 行足し、レジストリに `.with(新しいクレート::specs())` を足します。コアと、ほかのエンジンのクレートは触りません。
5. **取得元を登録する**。モデルの取得元（配布元の URL またはコミット、ファイルごとのサイズと SHA-256、ライセンス）を取得の一覧に足します。足すと `kikitori models list` と `kikitori engines list` に出ます。

重みの形が違う同系のモデル（別のファインチューンなど）は、新しいクレートを作らず、同じ実装を指す `EngineSpec` を別の `hf_repo` で足せば済みます。

## 確かめ方

- `kikitori engines list` に、名前・役割・対応する機能・使うモデルが出ること。
- トークンの時刻を出さないダミーのエンジンを `--asr` で選んで、話者つきの出力まで通ること（コアのテストにダミーのエンジンがあります）。
- 元の実装の出力と、短い音声の組で本文が一致すること。f16 など精度を下げる dtype は、一致の度合いを測ってから既定にするかを決めます。
- 重みが配布元のファイルのままで、キャッシュに派生物が書かれていないこと。

## 話者分離と発話区間を足すとき

`Diarizer` と `Vad` も同じ流れで足します。`Diarizer` は波形を受けて、話者番号つきの区間（`SpeakerSpan`）を返します。`Vad` は発話区間（`VadSpan`）を返します。選ぶ名前は `--diarizer` です。
